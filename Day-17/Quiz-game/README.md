# Day 17 — OOP Quiz Game

## Project Overview
A Python-based True/False quiz game developed as part of the 100 Days of Code course by Dr. Angela Yu.

## Features
- Presents True/False questions to the player.
- Checks answers and tracks the player's score.
- Uses Object-Oriented Programming (OOP) to organize the game logic.

## Concepts Practiced
- Python classes and objects
- Constructors (`__init__`)
- Methods and attributes
- Working with multiple Python modules

## Project Files
- `main.py` — Runs the quiz.
- `data.py` — Stores quiz questions and answers.
- `question_model.py` — Defines the question model.
- `quiz_brain.py` — Handles quiz logic and scoring.

## How to Run
1. Make sure Python is installed.
2. Open a terminal inside the `Quiz-game` folder.
3. Run `python main.py` (or `python3 main.py` on Linux).
