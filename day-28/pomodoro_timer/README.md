# Day 28 — Pomodoro Timer 🍅

## Project Overview
A Pomodoro Timer application built using Python
and Tkinter as part of Dr. Angela Yu's
100 Days of Code Python Bootcamp on Udemy.

The application uses the Pomodoro Technique to
manage focused work sessions and breaks.

## Features
- 25-minute focus sessions
- 5-minute short breaks
- 20-minute long breaks
- Start and reset buttons
- Countdown timer
- Visual progress indicators

## Concepts Practiced
- Tkinter GUI development
- Python functions
- Dynamic typing
- Countdown logic
- Using `after()` for scheduling
- Managing application state

## Project Files
- `main.py` — Application code
- `tomato.png` — Timer image (if used)

## How to Run
1. Make sure Python with Tkinter support is installed.
2. Open the Pomodoro-Timer folder.
3. Run `python3 main.py`.
4. Click Start to begin a focus session.
