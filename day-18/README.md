# Day 18 — Hirst Painting Project 🎨

## Project Overview
A colorful dot painting created with Python Turtle Graphics, inspired by Damien Hirst's artwork.

This project is part of the 100 Days of Code: The Complete Python Pro Bootcamp by Dr. Angela Yu.

## Features
- Creates a grid of 100 colorful dots.
- Randomly selects colors from an RGB color palette.
- Uses Turtle Graphics to draw and position the dots.
- Automatically arranges dots into rows.

## Concepts Practiced
- Python Turtle module
- RGB colors and color modes
- Random module
- Nested loops
- Turtle positioning and movement
- Using Colorgram to extract colors from images

## Project Files
- `main.py` — Python drawing code.
- `image.jpg` — Source image for color extraction.

## How to Run
1. Make sure Python is installed.
2. Open the project folder.
3. Run `python main.py` (or `python3 main.py` on Linux).
4. The Turtle window displays the painting.
